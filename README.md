# IPEva
Imputation Performance Evaluation

The files contain the IPEva Python script (IPEva.py), example imputed and validation VCF files (imputed.single.vcf.gz and truth.single.vcf.gz), population-level minor allele frequency and site heterozygosity annotations (population.maf.tsv.gz and population.shet.tsv.gz), genomic region definitions in BED format (regions.bed), and Example HTML report (IPEva_report.html) generated by IPEva using the example dataset.
